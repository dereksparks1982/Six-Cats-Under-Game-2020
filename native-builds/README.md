# Original native releases

These ZIP archives are untouched copies of the native Six Cats Under releases that were publicly downloadable from the original Team Bean Loop itch.io page at preservation time.

They are stored here so the released game remains recoverable if the original hosted downloads disappear in the future, as has happened to many older web and indie games.

Original game authorship remains with Team Bean Loop / Mosu and the credited creators. This repository is a preservation project, not a claim of authorship.

`MANIFEST.sha256` records cryptographic hashes of the archived ZIPs. `SOURCE-MAP.tsv` records the original itch.io upload IDs and public source endpoints used to retrieve them.
